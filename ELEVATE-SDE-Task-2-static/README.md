# ELEVATE-SDE-Task-2 — CredVault

A frontend-only CredVault certificate issuing and verification platform built for ELEVATE Skill Development Task 2.

## Features
- Home page with navigation
- Certificate request form with validation and Application ID
- Application tracking using Application ID
- Public certificate verification using Certificate ID
- Admin login (`admin` / `admin`)
- Applications table with Issue and Reject actions
- Certificates table with Revoke action
- Dummy data stored in browser localStorage
- Responsive dark UI inspired by the supplied CredVault reference
- No backend or database required

## Run
Simply open `index.html` in a browser. No npm install is required.
